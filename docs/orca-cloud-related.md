## English

```markdown
## More plugins for your OrcaSlicer workflow

- **[Organizer](https://cloud.orcaslicer.com/p/5bf381fd42d4)**: Arrange objects by their real outline and fill a build plate with more copies.
- **[Orca Print Calculator](https://cloud.orcaslicer.com/p/521c07cf6de2)**: Price every build plate: Spoolman filament cost, energy, labor, fees and a suggested selling price.
- **[Spooler](https://cloud.orcaslicer.com/p/50c35dcbd6f3)**: Your Spoolman spools and filament presets in OrcaSlicer, with what is left on each spool.
- **[U1 Control](https://cloud.orcaslicer.com/p/55b8c347d443)**: The Snapmaker U1 in OrcaSlicer: print setup, camera, toolheads, RFID, Spoolman and a file manager.
- **[Embedder](https://cloud.orcaslicer.com/p/58222d4f9e52)**: Cut magnet and NFC sticker pockets into a part, with a pause at the right layer to drop each insert in.

Each plugin works on its own; installed together they share data where it helps.
```

## Português

```markdown
## Mais plugins para o seu fluxo no OrcaSlicer

- **[Organizer](https://cloud.orcaslicer.com/p/5bf381fd42d4)**: Organize os objetos pelo contorno real e preencha a mesa com mais cópias.
- **[Orca Print Calculator](https://cloud.orcaslicer.com/p/521c07cf6de2)**: Calcule o preço de cada mesa: filamento do Spoolman, energia, mão de obra, taxas e preço de venda.
- **[Spooler](https://cloud.orcaslicer.com/p/50c35dcbd6f3)**: Suas bobinas do Spoolman e os perfis de filamento no OrcaSlicer, com quanto resta em cada bobina.
- **[U1 Control](https://cloud.orcaslicer.com/p/55b8c347d443)**: A Snapmaker U1 no OrcaSlicer: configuração de impressão, câmera, cabeças, RFID, Spoolman e gerenciador de arquivos.
- **[Embedder](https://cloud.orcaslicer.com/p/58222d4f9e52)**: Abra cavidades para ímãs e etiquetas NFC na peça, com uma pausa na camada certa para colocar cada inserto.

Cada plugin funciona sozinho; instalados juntos, compartilham dados onde ajuda.
```
